# README 修复方案（2026-10-19）

## 背景

Commit `22a07e6` 将 `README.md` / `README.en.md` 同步到 0.6.0 CLI。核验（对照 `src/govio/cli/meta.py`、`docs/specs/cli.md`）确认其余改动均与实现一致，但遗留 4 处问题需要修复。本方案由 subagent 执行，完成后在主会话逐项核验。

## 修复项

### 1.【必修】错误示例命令缺少 `--datasource`，展示的错误输出不可能出现

- 位置：`README.md:160`、`README.en.md:160`
- 问题：DuckDB 模式下 `--datasource` 已必填，且 `cmd_meta` 中 `--datasource` 校验先于 `--schemas`（`src/govio/cli/meta.py:693-698`）。示例命令缺 `--datasource`，实际会报 `❌ DuckDB 模式需要指定 --datasource`，永远不会打印示例中的 schema 列表。
- 改法（两个文件同一处）：

旧：

```
$ govio-cli meta meta --source duckdb --db ./data/sales.duckdb --schemas sales --output ./data/meta
```

新（参数顺序与同文档其他示例保持一致）：

```
$ govio-cli meta meta --source duckdb --db ./data/sales.duckdb --datasource sales --schemas sales --output ./data/meta
```

### 2.【应修】示例输出包含程序不会打印的注释行

- 位置：`README.md:152`、`README.en.md:152`
- 问题：`_generate_assets`（`src/govio/cli/meta.py:256`）只打印 `✓ Assets 已生成到: <path>` 一行。示例输出里的括号注释行是编辑说明混进了程序输出。该信息在两个文件后文「注意事项」（`--assets-dir`、请自行合并）已完整覆盖，无需重复。
- 改法：直接删除该注释行，不加替代文本。`✓ Assets ...` 行及其路径原样保留，不动。

旧（`README.md`，删除第二行整行）：

```
✓ Assets 已生成到: D:\Work\gov-io\govio\.agents\skills\govio\assets
  （路径由当前工作目录的 .agents/skills/govio/assets 解析而来，可用 --assets-dir 指定其他目录；如与应用读取的 assets 目录不一致，请自行合并）
```

旧（`README.en.md`，删除第二行整行）：

```
✓ Assets generated at: D:\Work\gov-io\govio\.agents\skills\govio\assets
  (resolved from .agents/skills/govio/assets under the current working directory; use --assets-dir to choose another directory; if this differs from the assets directory your application reads, merge them yourself)
```

新：两个文件均只保留 `✓ Assets ...` 一行，其后直接是空行 + `✅ graph ...` 行。

### 3.【应修】skills 目录树注释过时

- 位置：`README.md:274`、`README.en.md:274` 附近（`skills/govio/` 目录树中的 `assets/` 行）
- 问题：注释写「meta graph 自动生成」，但 meta graph 现在默认生成到 `.agents/skills/govio/assets`（同文档 234 行注意事项已说明）。在仓库根目录运行 `govio-cli meta graph` 不会填充 `skills/govio/assets/`。
- 改法：

旧（`README.md`）：

```
├── assets/               # 资源文件（meta graph 自动生成）
```

新：

```
├── assets/               # 资源文件（meta graph 默认生成到 .agents/skills/govio/assets）
```

旧（`README.en.md`）：

```
├── assets/               # Asset files (auto-generated by meta graph)
```

新：

```
├── assets/               # Asset files (meta graph writes to .agents/skills/govio/assets by default)
```
